# StudyTime

A simple website for study management.

## Description
StudyTime is a simple study management website that provides several useful tools to help you organize your study sessions.

You can find the following tools on the site:
- Timer : A timer for managing study sessions
- Task Manager : Create and manage your study tasks
- Notepad : Take notes directly on the website, notes are saved using localStorage
- Dark Mode : Enable dark mode and it saves your preference using localStorage

## Technologies 
The technologies used are:
- HTML5
- CSS3
- JavaScript
No external fraeworks required.

## Installation
To open the site, you need to:

```bash
git clone https://github.com/Christian-Lancini/StudyTime
```

```bash
cd StudyTime
```

And then open the **index.html**.
